Sì, è corretto. Serve un QSS più strutturato, ma non “più specifico sul contenuto”: più ricco sul sistema tipografico e sugli stati visuali.
Devi definire classi/ruoli generici tipo:

label.setProperty("textRole", "display")
label.setProperty("tone", "accent")
label.setProperty("weight", "bold")

E poi QSS:

QLabel[textRole="display"] {
    font-size: 64px;
}

QLabel[textRole="metric"] {
    font-size: 32px;
}

QLabel[textRole="body"] {
    font-size: 16px;
}

QLabel[tone="neutral"] {
    color: #2E2418;
}

QLabel[tone="accent"] {
    color: #8A1F14;
}

QLabel[weight="bold"] {
    font-weight: 700;
}
